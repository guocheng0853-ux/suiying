# Noto Serif SC Regular

Source: https://github.com/notofonts/noto-cjk/blob/main/Serif/SubsetOTF/SC/NotoSerifSC-Regular.otf

Simplified Chinese subset of Noto Serif SC, redistributed under SIL Open Font License 1.1. The file keeps the Noto Serif SC name. It is a smaller GB2312-plus-punctuation subset of the upstream SubsetOTF (11,625,800 bytes down to 2,635,076 bytes, 7835 glyphs), not the unmodified upstream file. Rare characters missing from this subset fall back to the system serif on Android 10 and later. Full license in OFL.txt. Used for paper-theme titles only; body text, controls and subtitles retain their existing fonts. Font is packaged locally; no font request is made during app use.
