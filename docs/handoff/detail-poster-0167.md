# 0.1.167 详情页方向 A（沉浸海报）

日期：2026-10-30。基线 main `6f9b475`（0.1.165 / code 166）。本版 **0.1.167 / versionCode 168**。

跳号原因：避开 zcode 测试修补。查过 `origin/main`、全部远程分支和开放 PR：最高仍是 0.1.165 / versionCode 166，没有 `zcode/*` 分支，也没有提交占用 0.1.166 / 167。本版不拿这一档，改用 0.1.167 / 168。

## 改了什么

Emby 库详情和影视仓 / 融合库详情用同一套海报，不再横屏左右分栏、竖屏另一套。

- 海报固定铺满，顶栏透明，返回是圆形按钮。
- 片名（衬线）和集数 / 日期 / 时长在左下。主按钮是胶囊「播放」或「继续」。
- 圆形按钮：线路、下载、收藏、更多。可点区域 48dp。
- 片源卡：视频名和分辨率 / 体积 / 码率，音轨。宽窗口（≥720dp）在标题右侧，窄窗口叠在按钮下面。
- 「更多来自 …」横向选集。当前集金色描边，看过打勾，有进度画金条。一季很长时先显示当前集附近，可点「更早的集 / 更后的集」。
- 「演职人员」横滑。Emby 用服务器给的人和头像；影视仓只有名字时用姓名，没有就不画。
- 「媒体信息」只在真有容器、编码、分辨率、帧率、字幕时出现。路径不展示。
- 下载按钮下的是当前「播放」会开的那一集，影视仓的线路名和地址来自同一组。剧集批量下载在「更多」。选集长按仍是「下载这一集」。
- 播放页「下载这一集」和推迟通知权限没有改。磁力、m3u8、DASH、只允许转码的 Emby 仍由原来的离线规则拒绝。

## 怎么在手机和平板上看

包名 `com.guocheng.mediapocket.next`，版本 0.1.167（168）。手机竖屏和小平板、平板横屏应是同一套，只是片源卡并排或换行。

1. 手机竖屏打开一部 Emby 剧：海报铺满，标题和金色「播放」在下方，四个圆按钮，片源卡在按钮下面，选集横滑，当前集有金边。
2. 平板横屏（或任意宽度 ≥720dp）打开同一部：片源卡在标题右侧，选集仍在下面。不要再出现左边整列海报、右边另一栏文字。
3. 点「播放」仍进原来的播放器。有进度时按钮是「继续」。
4. 点下载，下的是按钮要播的那一集。剧集点「更多 → 批量下载」，季列表还在。
5. 有多版本时点线路，选中的名字出现在片源卡上，再点播放用这一版。
6. 影视仓详情同样看一遍。换线路后，下载和播放必须是这一条线路（不要下成第一条）。长按某一集仍可单集下载。
7. 收藏仍走原来的收藏列表；第一次收藏若需要通知权限，仍会问。
8. 没有演职员或没有媒体流时，这两段不出现，不要出现编造的码率或人名。

本交接没有签名包，没有在 PJZ110 或 OPD2401 上点开这些页面。JVM 101 项已通过，含 `PosterDetailRulesTest`。

## 残留风险

- 没有真机或模拟器截图。720dp 换行、挖孔安全区、大字号是否把「播放」挤出第一屏，都还没在设备上看过。
- 片源卡是半透明深色，不是系统级背景模糊。Android 8 起做不到只模糊卡片背后的海报。
- Emby 剧集的片源卡要再请求一次该集的 `Items`（原来的季列表不带 MediaSources）。这次请求失败时卡片留空，播放不受影响。
- 影视仓通常没有编码和体积，卡片只显示线路名和集名。
- 换季不改主按钮指向的那一集（和原来一样，主按钮只在第一次决定）。批量下载跟的是当前看的这一季。
- 从详情点播放会清掉详情正文（原来 `work()` 就这样）。从播放器返回时，页面可能只剩状态行，需要再进一次详情。
- 浅色陶土主题下，播放按钮用陶土色，海报上的字仍是浅色，和纸色页面其他屏不完全一样。
