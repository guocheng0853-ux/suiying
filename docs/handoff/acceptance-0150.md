# 0.1.150 播放页精修与平板验收

日期：2026-10-27。基线 main `c3266ca`（0.1.149），版本 0.1.150 / code151。沿用既有 Apple TV 播放结构及“剩…看完”，本轮只打磨现有界面。

## 改动

- Media3「更多」移除音轨、字幕、选集三个重复入口；底栏仍提供这三项。
- VLC 顶栏比例单击显示短 HUD，长按菜单仍保留。Media3 保留原来的比例列表，选择不同模式后给出短反馈。比例按钮提供当前模式的无障碍状态。
- 状态文字 11sp → 12sp；大字号增加顶部预留，网速限制在时钟右侧可用空间并单行省略。
- 控件显示时黑色遮罩由35%增至55%，白场中央白色图标的理论对比度达到4.5:1；播放画面隐藏控件时的亮度不变。
- TalkBack 触摸探索启用时保留播放控件；原生锁屏解锁按钮不再定时消失，Media3 提供可访问的48dp解锁按钮。补充播放进度与速度标签。
- 移除未使用的倍速药丸控件、动画与顶栏logo下载死分支，更新过时注释。
- 窄窗口截图发现 Media3 截图按钮与后退15秒按钮重叠：截图按钮改用已有侧栏定位规则。

## 真机与证据边界

首轮播放验收只操作 OPD2401 / Android16 平板。测试为本地合成 H.264/AAC 白场视频和合成 Emby 剧集，未访问真实片源进行本轮播放验收。

| 项目 | 已取得的证据 |
| --- | --- |
| 普通字号白场 | VLC 与 Media3 实际出画面、进度推进；查看原尺寸截图，中央传输操作可见 |
| 菜单去重 | 实际 Media3「更多」含播放设置、弹幕、音效、字幕样式等，无独立音轨/字幕/选集项；底栏分别能打开实际音轨、字幕及两集列表 |
| VLC 比例 | 单击后实际节点出现“画面比例 · 拉伸”；TalkBack 记录到 TYPE_ANNOUNCEMENT 同文事件，按钮状态为拉伸 |
