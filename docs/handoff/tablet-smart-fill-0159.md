# 0.1.159 平板智能满屏

日期：2026-10-29。基于 main `30b196b`（0.1.158 / code159），本版0.1.159 / code160。用户要求将随影手机上的画面自动铺满适配到平板。

## 问题与修正

0.1.158处理的是平板沉浸窗口、系统栏和控件边距；智能缩放仍使用0.1.152为手机约2.2:1宽屏设定的12%裁切、10%拉伸上限。OPD2401横屏3000×2120播放16:9时，两项上限刚好不足以铺满，算法退回完整画面。

本版复用既有≥600dp平板判断，将平板智能满屏总裁切上限设为20%（每边最多10%），单轴拉伸仍不超过10%。手机计算保持原样。VLC缩放、Media3视频尺寸及VLC比例按钮的画面相同比较都带入设备分类，避免画面已填满而按钮仍按手机算法判断。

不增加画面模式，仍是智能满屏、完整画面、填满裁切。保持用户手动选择与双指缩放；极宽电影、竖屏等差距超限时继续显示完整画面，不无限拉伸。素材文件本身编码进去的黑边不属于本次检测范围。
