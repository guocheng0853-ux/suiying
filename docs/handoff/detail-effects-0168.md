# 0.1.168 详情页跳至与换集主视觉

日期：2026-10-30。基线 main `8ba7e02`（0.1.167 / code 168，沉浸海报已合，含 Windows 签名包和真机点检）。本版 **0.1.168 / versionCode 169**。

版本：查过 `origin/main`、全部远程分支和开放 PR。清单里最高是 0.1.167 / versionCode 168。没有 `zcode/*` 分支，没有人占用 0.1.166 / versionCode 167，也没有人占用 0.1.168 / 169。本版用 0.1.168 / versionCode 169。

## 改了什么

Emby 库详情和影视仓详情都加了两处，手机和平板仍是同一套 PosterDetail，只按窗口宽度决定片源卡并排还是换行。

### 跳至

「更多来自 …」右侧箭头打开对话框：标题「跳至」，输入框占位「输入要跳至的集数」，按钮「取消」「确定」。有多季或多线路时，标题文字仍打开原来的季 / 线路菜单，箭头只负责跳集。

确定后滚动选集条到该集，并选中它。主「播放 / 继续」、片源卡、集名 / 日期 / 时长和瓦片上的当前集金框，跟点这一集的瓦片相同。点瓦片改为选中，不再直接进入播放器。播放仍走左下主按钮。长按仍是「下载这一集」。

- Emby 只认 `IndexNumber`。没有这个字段，或这一季没有该集，提示「没有第 N 集」，不用列表里的第 N 条顶替。
- 影视仓先从选集名解析集数，顺序是 `SxxEyy`、「第 N 集」、`EP` / `E`、整段纯数字、「12. 标题」这种开头序号。同号取第一条。解析不到，再按当前线路里 1 起的列表序号（和界面上能列出来的前 1000 条同一范围）。还对不上就提示没有这一集。

### 换集后的主视觉

不重建详情页，不走会闪白的整页加载。

- Emby：这一集有 Primary 的 tag 时，主海报换成这张；加载失败再试 Backdrop（有 tag），再没有父级 Backdrop（有 tag），最后才是系列 Primary。这一集自己没有图时，主海报留着打开详情时已经铺上的系列背景。元信息和主按钮指向这一集。片源卡先清空，等这一集的 `Items`（带 MediaSources）回来再填，避免短暂显示上一集的文件名。
- 影视仓：协议没有每集图时继续用 `vod_pic`。换集后标题下的集信息、主按钮要播的地址、片源卡上的集名会更新。选集名里单独出现图片地址，或播放地址本身就是 jpg / png / webp / gif 时，主海报才换成这一集。不按集数去猜文件名。选集瓦片仍用整部 `vod_pic`。

### Emby 选集瓦片不再留黑

`EmbyCue.episodesPath` 的 Fields 在原来的 Overview、RunTimeTicks、UserData 之外加上 ImageTags、BackdropImageTags、SeriesPrimaryImageTag、ParentBackdropItemId、ParentBackdropImageTag。

瓦片图顺序：Thumb（有 tag）→ Primary（有 tag）→ SeriesPrimary（有 tag）→ 系列 Primary（SeriesId，不带 tag）。用已有的 `TvPosterImages.loadPoster(..., fallbacks)`。没有 tag 的单集 Primary 不请求，避免服务器抽帧 500 后瓦片一直是黑的。没有对整季调用 ThumbnailSet。

## 没有改的

- 下载拒绝规则。磁力、m3u8、DASH、只允许转码的 Emby 仍不能下。
- 播放页「下载这一集」和推迟通知权限。
- 圆形下载按钮仍下载主按钮将要播放的那一集。剧集批量下载仍在「更多」。
- 换季本身不改主按钮（和 0.1.167 一样）。在新的一季里点瓦片或跳至之后，主按钮才改到这一集。

## 怎么看

包名 `com.guocheng.mediapocket.next`，版本 0.1.168（169）。

1. 打开一部多集 Emby 剧。主海报仍是沉浸背景。点「更多来自 …」右侧箭头，输入一个存在的 IndexNumber，选集条滚到该集并出现金框。左下集数、日期、时长变成这一集；有进度时按钮是「继续」。片源卡变成这一集的文件，而不是上一集。
2. 再点另一集的瓦片，应停在详情页，主海报如果这一集有 Primary 就换图，没有就仍是系列背景。点主按钮才进入播放器。
3. 输入不存在的集数，对话框留着，并提示没有这一集。
4. 影视仓详情同样点箭头。选集名是「第 65 集」时输入 65 应选中它。名字解析不出集数时，输入 1 选当前线路的第一条。换集后片源卡上的集名和主按钮地址要一起变。没有单集图时主海报仍是 `vod_pic`。
5. 长按某一集仍可单集下载。磁力或 m3u8 仍会被拒绝。
6. 平板宽屏（≥720dp）片源卡仍在标题右侧，不要回到左右分栏。

本交接没有签名包，没有在 PJZ110 或 OPD2401 上点开跳至或换集。JVM 101 项已通过，含跳集规则、主视觉链和 Fields 断言。

## 残留

- 没有真机。对话框宽度、键盘是否挡住「确定」、金框滚进可视区域，都还没在设备上看过。
- 点瓦片从「直接播放」改成「选中」。想马上播，需要再点一次主按钮。
- Emby 片源卡仍要再请求一次该集的 `Items`。请求失败时卡片留空，播放不受影响。
- 换季后、还没在新季里点集时，主按钮仍指向打开详情时决定的那一集。
- 影视仓只有在选集名或播放地址里真有图片链接时才会换主海报。多数源不会变图，只会变字和播放目标。
- 标记已看仍可能按「继续看的那一集」重算主按钮，金框不一定立刻跟过去。下一次点选或跳至会再对齐。
- 从详情点播放仍会清掉详情正文。从播放器返回时，页面可能只剩状态行。
