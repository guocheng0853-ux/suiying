## 优先问题与精修方向

1. **P1 对比度。** 首页 `onHi`、两类详情 `accentInk` 给陶土底配白字，普通按钮用亮度 0.45 切换字色，均不能保证 4.5:1。保留填充色，按相对亮度选择原有暖墨/纸白，边界才用黑白兜底。另把等待框文案/转圈接入当前主题。
2. **P1 触控、焦点与读屏。** 顶栏 40/44dp、季/类型/线路 36dp、影视仓选集 42dp、服务器菜单 44dp；Media3 的进度条触摸行回退成 32dp。扩到 48dp，保留细进度线；自绘文字操作增加按钮语义、焦点与选中状态；设置开关整行提供正确名称和值。
3. **P1 长文字。** 设置右侧当前值最多占 200dp，名字和当前值互抢；菜单标题单行截断、右值无上限。设置值移到名称下，菜单标签允许两行、值限宽，保持原回调和滚动位置。
4. **P2 跨页主题。** 暗金设置的开关仍青色；来源菜单仍紫灰，市场原生外壳蓝绿。下载返回按钮为系统默认。沿用现有主题修齐，不改变外部市场网页内容或加滤镜。
5. **P2 首次使用和旧入口。** 搜索仍有已要求移除的 TorrentClaw 专用入口；空收藏没有下一步；登录表单无固定标签且预填示例地址；下载提示错误指向右上角。移除专用入口，补收藏引导、固定标签/键盘类型，修正帮助。保留用户插件、服务器、来源配置及观看记录。

## 认知负担与情绪路径

中等：主任务、分组和渐进披露有效；信息识别/术语一致性两项不足。片库大量影片属于浏览内容，不按“四个选项”机械扣分。首次用户 Jordan 会在输入后忘记字段用途；单手用户 Casey 易误触小筛选；读屏/大字用户 Sam 容易丢失选中状态或遇到名称挤压。海报/续播是体验高点，失败/空态/登录是低点。保留“剩…看完”这一产品信息，以清楚的恢复路径弥补低点。
