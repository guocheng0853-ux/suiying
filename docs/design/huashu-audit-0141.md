# 随影界面 · 花叔Design 规范审查（0.1.141 前）

依据：花叔Design（huashu-design v3.0.0）SKILL.md「窄桥」第 5 条（模板装饰、可读性底线）、critique-guide.md（8pt 网格、≤2 字体、颜色受控、对齐统一、字号层级）、typography.md 第 4 章（中文排印）。审查对象：0.1.140 main，全部页面代码（首页、详情、我的、菜单、两个播放器）。没有逐屏真机截图，播放器部分以用户 2026-10-25 发来的真机截图为准。

## 发现

| # | 规范 | 现状 | 级别 |
|---|---|---|---|
| 1 | 字号层级 ≤5 档，标签 ≥12 | 代码里出现 18 档字号（9–34sp），9/10/11sp 低于 12sp 底线（海报来源标签 9sp、规格标签 11sp、底栏 11sp、状态行 11sp） | 重要 |
| 2 | 中文不收负字距；中文字距 0–0.05em | 宋体标题统一 -0.02 / -0.025；小标题 0.08 | 重要 |
| 3 | 间距、圆角成系统 | 圆角 15 种取值（4/6/8/10/12/14/16/17/18/20/22/24/26/28/32），两套外观按钮圆角不同（12 / 24–28） | 重要 |
| 4 | 模板装饰：标题上一行小标签 | 首页大图片名上方的「今日推荐 · 剧集」「最新入库 · EMBY」 | 重要 |
| 5 | 模板装饰：按钮 / 标题尾巴的箭头 | 栏目标题「热门剧集 ›」「媒体库  ›」，按钮「查看详情 ›」 | 优化 |
| 6 | 模板装饰：「A · B · C」中点串联 | 用在标签、栏目名、菜单副标题（「最新 · 库名」「从当前位置继续 · …」）；也用在年份 / 类型 / 时长这类数据行 | 优化（数据行保留，见决定） |
| 7 | 触控 ≥48dp（安卓） | 播放器顶栏 40dp、底栏图标 40dp | 重要 |
| 8 | 功能优先、删掉不让设计变差的元素 | 播放器：正中白色大圆盘图标不居中、压到底部面板；底部面板高而空（音轨 / 字幕 / 选集被挪进「更多」）；顶部按钮有的带圆底有的不带 | 致命（真机截图） |
| 9 | 颜色受控 | 页面两套外观各 1 主 1 强调 + 灰阶，符合；播放器进度条片头蓝 / 片尾紫是功能色，保留 | 通过 |
| 10 | 字体 ≤2 种 | 标题内置思源宋体、正文系统黑体，符合 | 通过 |

## 决定

- 字号收成 5 档：12 / 14 / 16 / 20 / 28sp（说明·标签 / 次要文字 / 正文·按钮 / 栏目标题 / 片名）。旧取值按就近档折算，最小 12。
- 中文一律字距 0；只有全大写西文标签允许 0.08。
- 间距只用 4 / 8 / 16 / 24 / 32dp；圆角三档：小 8（标签、缩略图）、中 12（按钮、卡片）、大 20（面板、弹层），圆形控件用正圆。两套外观共用，不再一套方一套圆。
- 删掉首页大图片名上方的小标签；来源信息并入信息行。
- 栏目标题去掉「›」，右侧改成灰色「全部」；按钮去掉尾巴箭头。
- 中点只留在数据行（年份、类型、时长、码率这类并列数据），标签、栏目名、菜单副标题里的中点改成逗号或拆开。
- 播放器：结构参照 Apple TV App 的播放页（用户 2026-10-25 指定；环境无法截图，按公开认知拆规则，未亲眼对照），规范和产品味按花叔Design：
  - 借 Apple TV：控件出现时整块画面压暗约 35%；顶部只有不带底的白色图标（左返回，右解码 / 比例 / 画中画 / 更多）；正中「后退 N 秒 / 播放 / 前进 N 秒」三个白色图形，无圆底；底部左剧名（14 灰）、集名，右一排小图标（上一集、下一集、音轨、字幕、选集、倍速）；下面通栏 4dp 进度条；进度条下左已播时间。
  - 守花叔Design：不照搬 Apple 的「−17:58」，进度条右下用随影自己的「剩 X 分，HH:MM 看完」（上一轮评审里唯一被点名的产品味）；集名用全 App 统一的思源宋体 20sp；已播进度用外观强调色（暖白陶土为陶土，影院暗金为金）；可点区域 48dp；字号只用 12 / 14 / 20；中文字距 0；音轨、字幕、选集回到底部，「更多」里不再重复。
  - 定稿样图：画布「随影界面样图」右栏「播放器 4」。
